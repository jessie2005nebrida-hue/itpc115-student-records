# Student Records Application

A simple Laravel web application for managing student records built for ITPC 115 - System Integration and Architecture 2.

## Features
- View all student records
- Add a new student record
- Edit existing student records
- Delete student records
- Validation for required and unique fields

## Prerequisites
- PHP (v8.1 or higher)
- Composer
- Node.js & npm
- MySQL / XAMPP
